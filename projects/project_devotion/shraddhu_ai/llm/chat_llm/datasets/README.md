# Datasets Repository 
 
This directory contains all datasets used for training, evaluation, and testing. 
 
## Structure 
- raw/ - Original unprocessed data 
- cleaned/ - Processed and filtered data 
- instruction/ - Instruction-tuning datasets 
- conversations/ - Dialogue and chat datasets 
- knowledge/ - Knowledge base and facts 
- embeddings/ - Pre-computed embeddings 
- evaluation/ - Test and evaluation sets
